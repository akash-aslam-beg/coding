# Sources and reuse

Some exercises follow external lessons. The explicit references recorded in the source material include:

- [Codebasics: Python and machine learning](https://github.com/codebasics/py).
- [Codebasics: deep learning with Keras and TensorFlow](https://github.com/codebasics/deep-learning-keras-tf-tutorial).
- [Stephen Welch: Neural Networks Demystified](https://github.com/stephencwelch/Neural-Networks-Demystified).
- [Melbourne housing dataset](https://www.kaggle.com/anthonypino/melbourne-housing-market), linked in the regularization notebook.

These are learning and dataset references, not blanket authorship credits for every notebook. Specific author credits already present in the notebooks remain, and dataset links are recorded in the code and topic READMEs.

Some numerical-method and Pandas study notes do not record their original source URL. Coursework notebooks also contain textbook/problem screenshots. Their reuse terms still need to be established before public release.

No blanket license is applied to this mixed collection. Third-party code, datasets and figures retain their original terms. Attribution alone does not grant redistribution rights.

The composite workbooks in this repository are generated examples. The monolayer `.data` files are generated sheet geometries. Raw experimental workbooks and simulation trajectories are separate from this collection.
