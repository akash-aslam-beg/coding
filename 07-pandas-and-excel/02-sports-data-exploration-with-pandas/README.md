# Sports-data exploration with pandas

Exploring Premier League player statistics with Pandas. Min is playing time in minutes; Pos is position, CrdY is yellow cards, and CrdR is red cards.

## Notebooks

- [Exploring datasheets](01-exploring-datasheets.ipynb)
- [Sports-data exploration with pandas 2](02-sports-data-exploration-with-pandas-2.ipynb)

## Data

- `data/premier-player-23-24.csv` is required for the file-based cells.
- `data/details.xlsx` is required for the file-based cells.
